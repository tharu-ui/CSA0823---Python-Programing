### Technologies Used
- Python 3
- Visual Studio Code

### How to Run the Programs

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the assignment folder.
5. Run the required program.

Example:

```bash
python task1.py
```
